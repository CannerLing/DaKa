# 今日份打卡 (daka)

> 本地优先的习惯打卡 App · 无账号 · 无广告 · 无数据上传 · 约 73KB

一个把"打卡、提醒、日历、饮食记录"装进口袋的轻量应用。所有数据只存在你自己的手机上，不联网、不上传、不需要注册登录。

## 下载安装

从 [Releases](../../releases) 页面下载最新版 APK，直接安装即可。

- 系统要求：Android 7.0（API 24）及以上
- 安装时如提示"未知来源应用"，允许即可（APK 未上架商店的安装提示属正常现象）
- 覆盖安装可保留全部数据，无需卸载旧版

## 功能

- **习惯打卡**：内置习惯模块 + 自定义项，支持休息日、按周配置
- **到点提醒**：闹钟常驻系统层，关掉/划掉 App 也能准时提醒（前台服务 + 多层保活）
- **日历回顾**：打卡记录、照片、饮食明细永久保存在日历上，颜色一眼可读
- **AI 饮食记录**：输入"一碗牛肉面加卤蛋"自动识别热量；本地食物库 364 种离线可用；可选接入你自己配置的大模型 API（完全 API 模式）
- **摄入目标环**：按 TDEE 计算每日热量目标，超标时红绿双圈一眼看出超了多少

## 隐私

- 所有打卡记录、照片、饮食日志**仅存储于设备本地**
- 应用本身不收集、不上传任何数据
- "AI 识别"功能为可选项且默认关闭：开启后仅会把当餐的文字描述发送到**你自己配置的** API 服务器，本应用不经手、不存储
